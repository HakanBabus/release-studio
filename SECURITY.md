# Security policy

Release Studio is a static client-side app. It does not have an application server, account system, or data store.

## Reporting a vulnerability

Please do not publish details of an exploitable issue in a public issue. Use GitHub's **Report a vulnerability** option for this repository if private vulnerability reporting is enabled. If it is not available, contact the repository owner through their GitHub profile and include a concise description and reproduction steps.

## Supported versions

Security fixes are made on the default branch. Use the latest published version when reporting an issue.
